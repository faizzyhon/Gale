"Windows protected your PC"

Gale's installer isn't code-signed yet, so Microsoft Defender SmartScreen may warn you the first time. Click More info, check that the file name is Gale_Setup_0.7.0.exe, then click Run anyway. You can compare the file with the SHA-256 shown above: in PowerShell run Get-FileHash .\Gale_Setup_0.7.0.exe.
