Get Gale for Windows

One installer sets up Gale, the browser extension and the video tools. It asks for administrator approval once and installs for everyone on the PC. Installing a newer version updates Gale in place and keeps your downloads list.

System requirements

WindowsWindows 11, or Windows 10 version 1809 or later, 64-bit
WebView2Built into Windows 11 and current Windows 10. The setup installs it if it's missing.
Disk spaceAbout 400 MB
BrowserGoogle Chrome or Microsoft Edge, version 116 or later (optional)
AdministratorNeeded once to install. Gale itself runs as a normal program.

"Windows protected your PC"

Gale's installer isn't code-signed yet, so Microsoft Defender SmartScreen may warn you the first time. Click More info, check that the file name is Gale_Setup_0.4.0.exe, then click Run anyway. You can compare the file with the SHA-256 shown above: in PowerShell run Get-FileHash .\Gale_Setup_0.4.0.exe.
